클라이언트에서 WAS로
평가·질문 식별자와 사용자가 녹음한 음성 데이터가 답변 제출에 포함됩니다. 사용자 ID는 인증 정보에서 WAS가 확인합니다.

      
WAS에서 OpenAI API로
STT에는 원본 음성, 대화 분석에는 질문·전사·필요한 음성 맥락, TTS에는 확정된 질문 텍스트와 음성 설정이 전달됩니다.

      
DB 저장 범위
DB에는 답변·작업·전사·질문과 음성 객체 메타데이터를 저장합니다. 음성 바이너리 저장소(MinIO)는 요청된 노드 목록에 없어 다이어그램에서 생략했습니다.

    

    
요청에서 지정한 Browser · Client · WAS · DB · OpenAI API 다섯 경계만 표시했습니다. 음성 전송의 구체적 HTTP 방식은 구현 시 확정해야 합니다.
