인증
Access JWT는 DB에 저장하지 않습니다. Refresh Token은 해시와 만료·폐기 정보만 저장하고 쿠키로 전달합니다.

      
질문과 답변
AI 질문은 question, 질문당 최대 하나의 사용자 답변은 answer에 저장합니다. 답변의 processing_status는 전사 처리 상태입니다.

      
음성 및 결과
MinIO의 단일 버킷에 음성을 저장합니다. DB에는 프리픽스가 포함된 object_key와 최종 보고서·항목 결과·피드백을 저장합니다.

    

    
현재 기본 ERD의 9개 테이블을 기준으로 한 흐름입니다. AI 처리 중간 결과는 별도 테이블에 저장하지 않습니다. 음성 전송의 구체적 HTTP 방식은 구현 시 확정합니다.
