# Entities

공유되는 업무 개념의 데이터·조회·표시를 슬라이스로 구성한다. 현재 `user`가 인증된 사용자 상태를 관리한다. 평가 기능을 구현할 때 아래 모델을 추가한다.

- `evaluation` — 평가 설정·진행 상태·현재 질문과 답변 조회
- `assessment-report` — 최종 수준·항목별 결과·근거·피드백 조회와 표시

슬라이스는 필요한 `api`, `model`, `ui` 세그먼트와 공개 `index.ts`를 갖는다. 기존 서버의 tRPC 입출력 계약을 사용하고 Prisma 모델을 가져오지 않는다. 서로 다른 entity 슬라이스의 조합은 상위 레이어에서 수행한다.

DB 테이블마다 entity 슬라이스를 만들지 않는다. 로그인·답변 제출·재개 같은 사용자 동작은 features에, 페이지별 구성은 pages에 둔다.
